### Backend
- **ASP.NET Core Web API (.NET 8)** — REST API architecture
- **Entity Framework Core** — SQL Server integration
- **ASP.NET Identity & JWT** — Secure authentication and Role-Based Access Control (RBAC)
- **Swagger/OpenAPI** — API documentation and testing
- **ClickUp REST API** — Third-party task synchronization

### Frontend
- **React + Vite** — Core architecture & TypeScript for type safety
- **React Router & Axios** — Navigation and API communication
- **Recharts** — Data visualization for workload dashboards
- **CSS3** — Custom responsive styling

## 🛠️ Setup Instructions
1. **Database:** Update the connection string in `appsettings.json` (Backend).
2. **Backend:** Navigate to `/backend` and run `dotnet run`.
3. **Frontend:** Navigate to `/workload-frontend`, run `npm install`, then `npm run dev`.
